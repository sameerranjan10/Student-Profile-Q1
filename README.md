# Student Profile App

A simple React app demonstrating functional components and props.

## What it does
- `Student` is a functional component that receives `name`, `course`, and `college` as props and displays them using JSX.
- `App` renders two `<Student />` components with different data.

## Setup

```bash
npm install
npm start
```

Then open http://localhost:3000 in your browser.

## Files
- `src/Student.jsx` — the reusable Student component
- `src/App.jsx` — renders two Student components
- `src/App.css` — basic card styling
- `src/index.js` — app entry point
